# Playtest notes

Three lines after every run, while it is fresh. Yours first; other people's
are worth more. Say them to Claude ("log a run: ...") or type them here.

**The three questions:**
1. **Good:** one moment that felt good.
2. **Annoyed:** one thing that got in the way.
3. **Confused:** one thing you did not understand or expect.

Also note how it ended: which map and wave you reached and how many lives
were left. That is the only difficulty data the project has.

| | | | | | | |

## What to do with them

- The same complaint three times is a roadmap item.
- A "good" that keeps coming back is the thing to protect and build on.
- "Confused" from someone who is not you outranks everything else.
- When five people other than Faisal have a row here, the map 1 slice can
  be judged and maps 2 to 4 can start.
